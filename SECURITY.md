# Security

The hosted server at https://getmovely.co.uk/mcp is read-only: no tool writes,
sends or stores anything on a person's behalf. `draft_letter` returns a link
whose text travels in the URL fragment; the person sends the letter themselves
on the website.

To report a vulnerability, e-mail hello@getmovely.co.uk with "security" in the
subject. Please do not open a public issue for it.
